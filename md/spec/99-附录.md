## 1. 术语表（含易混淆的命名映射）

### 1.1 实表名 ≠ 文档里常写的名字 ⚠️

| 文档/直觉里的名字 | **实际表名** |
|---|---|
| `habit_records` | **`habit_logs`** |
| `moods` | **`mood_logs`** |
| `memorial` | **`anniversaries`** |
| `categories`（习惯/待办分类） | **`user_categories`** |

### 1.2 业务术语

| 术语 | 含义 |
|---|---|
| **L1 / L2 / L3** | 账户三层：大类（派生）/ 类型（18 个）/ 机构（银行 322 家） |
| **净资产** | `SUM(全部 accounts.balance)`（信用类存负数）；旧称"总资产"，语义已变 |
| **口径开关** | `exclude_budget`（不计入预算）/ `exclude_stats`（不计入收支），**互不影响** |
| **核销** | 用 `settle_of` 指向原笔的反向流水；状态**派生不落库** |
| **daily 指标** | `health_vocab` 里预期每天有的指标，进"今日完成度分母" |
| **events / days** | 健康事件真源（一天多次）/ 日汇总缓存 |
| **domain** | `user_categories` 里区分 `habit` / `task` |
| **tint** | `IconBox` 的 6 种彩色圆底配色 |
| **落位口诀** | 流水→记录，档案→我的，镜子→统计，今天→首页 |

### 1.3 前端别名

| 后端 | 前端 | 说明 |
|---|---|---|
| `today_completed` | `today_done` | 需 normalize |
| `AccountType` | `saving/credit/huabei/wechat`（旧 4 值）+ 14 新值 | |
| `BudgetScope` | `overall` / `category` | 后端是 `total` / `category`，注意映射 |

## 6. 文档维护约定

1. **`md/spec/` 是活文档**，描述"现在代码里是什么样"。改了代码要回来改它。
2. **`md/archive/` 是只读留档**，不再修订；冲突时以 `spec/` 为准。
3. 新批次设计可另起目录，但**落地后必须把结论回写进 `spec/`**。
4. 关键结论（尤其"已实现/未实现"）附 `文件:行号` 证据。
5. 双端差异必须显式写出。
6. 每次更新同步维护：README §5 状态一览、本文 §3 缺陷清单、本文 §4 断线清单。
