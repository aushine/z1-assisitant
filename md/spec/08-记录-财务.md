# 08 · 记录 · 财务（记账 / 账户 / 预算）

> 财务视图是页内 **4 段**：`流水 | 日历 | 预算 | 账户`（两端一致）。

---

## 1. 账户体系（三层）

```
L1 大类（派生，不落库）      L2 类型（18 个，落库）            L3 机构
  资金 asset      ←──── 现金 / 储蓄卡 / 支付宝 / 余额宝 / 微信钱包 / 储值卡
  信用 credit     ←──── 信用卡 / 花呗 / 白条 / 贷款 / 其他信用
  理财 investment ←──── 基金 / 股票 / 银行理财 / 黄金 / 其他投资
```

| 规则 | 说明 |
|---|---|
| **L1 由 L2 派生** | `internal/utility/account_vocab.go`（⚠️ 放 utility 不放 model，避免循环导入） |
| **L2 保留 4 个旧值** | `saving` / `credit` / `huabei` / `wechat` 一字不改 |
| **⚠️ 信用类余额存负数** | 净资产 = `SUM(全部 balance)`；标签是「**净资产**」不是「总资产」 |
| **L3 只在储蓄卡/信用卡必选** | 贷款可选；其余不选机构 |
| **银行清单** | 常量 `banks.ts`（322 家，153 家有 logo），**不建表**；无 logo 走**文字徽标兜底** |
| **`institution`** | `varchar(20)`，不加索引，后端只校验长度 |

### 1.1 图标来源分层（⚠️ 重要）

| 场景 | 图标来源 | 可自选？ |
|---|---|---|
| 品牌命中的类型（支付宝/微信/余额宝/花呗/白条） | `brand:<slug>` 自动带出 | ❌ **只读** |
| 已选机构的储蓄卡/信用卡/贷款 | 该银行 logo 自动带出 | ❌ **只读** |
| 其余（现金、储值卡、基金、股票、其他账户…） | lucide 默认图标 | ✅ **可编辑**（走 `IconPicker`，仅 lucide） |

- ⚠️ **品牌/银行 logo 不进自定义图标候选**，自定义图标**只在 lucide 里选**。
- emoji **仅保留渲染兼容**（存量账户照常显示，编辑保存时顺手换成对应 lucide，用既有 `ACCOUNT_ICON_KEYS` 映射）。
- 图标引用三态：`brand:<slug>` / `lucide:<Name>` / `<emoji>`；⚠️ **`icon` 列须为 `varchar(32)`**。

### 1.2 余额规则

- 所有 L1 都允许负余额（信用类天然为负；资金类透支/垫付未回是事实）。
- ⚠️ 「余额不足」拦截**只作用于 asset/investment**（4 处：Create / Update / Reverse / **Transfer**）；**「直接改余额」永不拦**（那是校正，不是记账）。
- 跨 L1 改类型：跨 `asset ↔ credit` 提示 + **余额自动取负**（后端不取负，是前端职责）；同 L1 不动。

## 2. 记一笔（录入）

### 2.1 金额输入

| 端 | 形态 |
|---|---|
| **移动端** | **自绘计算键盘** `AmountPad`：不调系统键盘（`readonly` + `inputmode="none"`），4 列 × 4 行 + 末行 `=`（左 1 列）/ `完成`（右 3 列） |
| **桌面端** | **表达式输入 + 失焦采纳**：`199/3` → 失焦后写回 `63.33` |

**求值语义**：支持 `+ − × ÷`；**左到右、不做优先级**（`1+2×3 = 9`）；**全程在「分」上做整数运算**；除不尽四舍五入到分；预览用 `≈`（被舍入），**不弹 toast**。
**算式不落库**（后端只存最终金额）。

**失焦采纳三条硬规则**：① 空框不动（不冒 `0.00`）② 无效表达式保留原文（`15/` 不被写坏）③ 有效则写回、统一 2 位小数。除不尽**不额外提示**。

**键盘与金额框"组成一块"**（移动端）：
- 金额框**同一 DOM 元素、不隐藏、不重建**，键盘升起时**平移到键盘正上方**；
- ⚠️ 金额框**必须移出 `.sheet-body`**（放进覆盖层 `.calc-dock`），否则被 `overflow` 裁剪；
- 视觉四条件：上下零缝隙 + 共用外圆角（金额框 `20 20 0 0`）+ 同一底色且**删掉键盘原有 `border-top`** + 投影只加在金额框上；
- ⚠️ `--calc-dock-h` 用 **ResizeObserver 运行时测量**（写死 token 会导致改键盘高度时忘改留白，最后一个字段被压住且不报错）。

### 2.2 日期与时间

| 端 | 形态 |
|---|---|
| 移动端 | **4 列滚轮**（年/月/日/时间），日列随年月联动（含闰年），时间 1 分钟粒度 |
| 桌面端 | `DatePicker` `type="dateTime"` |

⚠️ `happened_at` 本就是 `TIMESTAMP`，**不需要改表**。

### 2.3 两个口径开关

`exclude_budget`（不计入预算）、`exclude_stats`（不计入收支）—— **完全独立，不做任何联动**。
可见性：不计预算只在**支出**；不计收支在**支出/收入**；**转账都不给**。默认收在「更多选项」折叠区。

### 2.4 「性质」与三个财务功能

| source | 含义 | 入口 |
|---|---|---|
| `''` | 普通 | — |
| `balance_adjust` | 余额调整 | 编辑账户余额 |
| `reimburse` | 待报销 | 记一笔（支出侧） |
| `lend` | 借出 | 记一笔（支出侧） |
| `borrow` | 借入 | 记一笔（收入侧） |
| `refund` | 退款 | 从原笔详情发起 |

- **不建新表**，靠 `source` + `contact`（对方）+ `settle_of`（关联原笔）三列。
- **状态派生不落库**：是否存在指向本笔的核销记录 ⇒ 支持部分核销。
- **资金流走真实流水** ⇒ 账户余额自动正确。
- 核销类动作（报销到账/收回/还回/退款）**从原笔详情页发起**（`SettleSheet` / `SettleDrawer`），不塞进记一笔。
- 「性质」用**单选 chip**；「对方」输入框只在选了非普通时出现。
- **默认同时开两个口径开关**，但**用户可见可改**（不是硬编码）。
- ⚠️ **退款不冲减支出**（复用 `exclude_stats`，零额外 SQL），只在原支出上标「已退 63.33 / 199.00」。
- ⚠️ **借出不计入总资产**（否则"账户余额之和 ≠ 总资产"），单独用债权债务卡展示。

## 3. 流水视图

### 3.1 筛选（已精简）

| 项 | 现状 |
|---|---|
| 工具栏 | **常态 1 行**：类型下拉（全部/支出/收入/**转账**）+ 搜索 |
| 账户筛选 | ⚠️ **降级为 chip，不是删除**：从账户页点某账户 → 跳流水页注入 `account_id`，显示为可移除 chip（复用 `.date-chip` 样式），**条件渲染不占行** |
| 类型筛选 | ⚠️ **走服务端**（`type` 为空 = 不加条件 = 全量含转账），客户端过滤会与分页打架 |
| 桌面端 | ⚠️ **保留账户下拉**（方案 B）：桌面端三个控件横排共 530px、内容区 ≈1000px，不挤；且"下拉是主动浏览、chip 是被动移除" |

### 3.2 顶部数据块（`SummaryCards`）

- 位置：**列表之上、视图第一块**（原位在列表之后，要滚到底才看见）。
- 左块：本月收入 ⇄ 本月支出（**整块可点翻面**）；右块：剩余预算 ⇄ 月结余。
- ⚠️ **右侧不再显示总资产**（与账户页「净资产」是同一件事，重复）。
- 口径**全部来自服务端** `GET /finance/summary?period=week|month|year`（早期是前端对"已加载记录"求和，数字不准）。
- 周期切换：点「月预算」那行小字 → 月 → 周 → 年循环（**不跳设置页**）。
- 两态记忆到 localStorage。
- ⚠️ **没有 `scope=total` 预算时显示「未设预算 · 去设置」**，不显示 ¥0、也不用分类预算凑。

## 4. 收支日历

- 位置：财务视图第 2 段（`流水 | 日历 | 预算 | 账户`）。
- **格子 = 当日净额一个数字**：`>0` 绿 + `+`；`<0` 红 + `−`；`=0` 中性；无记录空白。
  ⚠️ **红 = 支出、绿 = 收入**（记账惯例），与股市"红涨绿跌"**相反**。
- 点格子 → 月历**下方内联**当日明细卡（收入/支出合计 + 笔数 + 最多 3 笔 +「查看全部 ›」），**不做弹层**。
- 长按格子 → 以该日期打开「记一笔」补录（⚠️ 长按后要吞掉 click）。
- 数据：`GET /finance/calendar?month=YYYY-MM`（复用已有 `GroupByDay`；⚠️ 不能复用 `/stats/finance`，它只有 7d/30d/90d，`custom` 分支未实现，拿不到自然月）。
- 样式复用 = **只抽样式**（`_calendar.scss` 的布局与排版），⚠️ **不抽 `st-*` 语义色**、不抽 cells 计算与手势；分两批落地（先新代码，再改健康/经期并逐像素比对）。

## 5. 预算

| 规则 | 说明 |
|---|---|
| **周期滚动** | ⚠️ `used` 按 `period + 当前时间` 现算，**忽略冻结的 `start_date/end_date`**（存量零迁移，只在读时算） |
| **scope** | `total`（总预算）/ `category`（分类预算）；⚠️ **只允许设在一级分类** |
| **剩余预算** | 只统计 `scope=total` 且选定周期的预算；混入分类预算会**重复计算** |
| **编辑** | ⚠️ 后端无 update 端点，**编辑 = 删旧建新** |
| **子分类归集** | `SumExpenseByCategory` **必须含子分类**，否则给「餐饮」设预算却记「餐饮-三餐」，已用永远 0 |

## 8. 分类（两级）

- 一级 **12 支出 + 8 收入**，二级 **85 个（每个都有独立 icon）**，共 105 条/用户。
- **交互（移动端）**：记账表单里**一级内联平铺常驻**（打开即见，无需点击）；点「有二级」的 → 弹一层二级弹窗（首项 = 一级本身，标「只记大类」）；点「无二级」的 → 直接选中不弹。
- **交互（桌面端）**：一级 chip + **hover 浮出二级面板**（不占表单高度）；点一级 = 立即选中该大类。
- 有二级的大类用名字右侧 `›`（`ChevronRight` 12px）标记。
- **选择器内也能增删**：移动**长按**（`useLongPress`，500ms，⚠️ 禁用 `@contextmenu`）；桌面**右键 Dropdown + hover 显 `⋮`**。
- **聚合按 id**；渲染「按 id 查、快照兜底」。
- 管理入口：**我的 → 记账分类**（`/me/finance-categories`）；移动端另有 `/record/finance-categories` 覆盖层入口。

## 9. 债权债务

- 位置：账户视图下方的独立卡片（与账户列表**并存不混** —— 那是"别人欠我"，不是账户）。
