# 09 · 记录 · 健康（含经期与预测算法）

> 健康是「一组**可开关**的身体指标」，**经期是其中之一**（不是独立模块）。
> 边界：习惯 = 行为打卡（做没做）；健康 = 身体量化指标（测出来的数）。**饮水归健康**。

## 2. 数据模型（3 张表）

```
health_events（真源 · 一天多次 · 不延续）
      │ 同事务内 recomputeDaySummary
      ▼
health_days（日汇总缓存）
```

| 表 | 关键列 |
|---|---|
| `health_events` | `date`、`time_of_day "HH:mm"`、`metric_key`、`value_num` / `value_int`、`note` |
| `health_days` | `water_ml`（累计）、`weight_kg`、`bbt`、`sleep_hours`、`bowel_count`、`bowel_type` |
| `health_settings` | `metrics_enabled` json、`water_goal_ml`（1500）、`water_step_ml`（200）、`weight_goal_kg`、`setup_done_at` |

- `metric_key`：`water` / `bbt` / `weight` / `sleep` / `bowel`（只有 bowel 用 `value_int`）。
- ⚠️ **身体指标唯一写入路径是 `POST /health/events`**；`health_days` 是缓存。
- ⚠️ **`weight` 日汇总取最早一次**（晨起口径，与 `bbt` 一致），有重算脚本 `scripts/weightrecompute`。
- `health_settings` **懒创建**，`GET /health/settings` 永不 404。
- 排便形态 **4 档**（`None/OK/Soft/Hard/Loose`），**刻意不用 Bristol 7 型**。
- ⚠️ 日接口是**整体覆盖**语义：`saveDay` 必须「取回 → 合并 → 整体提交」，**只许提交 period / moods**；身体指标只走 `addEvent`。

### 3.1 关键设计约束

| # | 约束 |
|---|---|
| **C1** | 「今日健康」**不给每个指标独立卡片**（11 张全宽卡 ≈ 748px = 一屏） |

## 4. 心情（`mood_logs`，⚠️ 按小时）

- **`UNIQUE(user_id, date, hour)`**，`hour` 0–23。
- `mood` 1–5（0 = 该小时确无心情，**读取时向前延续**）；`energy` 1–3（NULL ≡ 不填）；`note` 不延续。
- ⚠️ **`hour` 不带 gorm `default` tag**（否则 hour=0 午夜会被当零值静默写成 12）。
- ⚠️ **`hour = 12` 是经期日记槽**（一天一条，与小时制共用同一张表）。
- `PUT /moods` 按 `(user_id, date, hour)` **upsert**；不传 `hour` 取服务器当前小时。
- ⚠️ 心情/精力是「往前**延续**」，身体指标是「**不延续**」 —— 两套语义别搞混。

## 5. 经期与预测算法

> ⚠️ **算法实现位置**：`internal/utility/period_algorithm.go`（**不是** `service/impl/period.go`，后者只做调用）。
> 前端**不做任何预测计算**。

### 5.1 三张表

| 表 | 定位 |
|---|---|
| `period_days` | **唯一事实源**（逐日打卡） |
| `period_cycles` | 幂等派生（可人工修正） |
| `period_settings` | 每用户一行，懒创建（`avg_cycle_length 28`、`avg_period_length 5`、`luteal_length 14`、`goal`、`show_fertile_window`、`irregular_alert`、`disclaimer_accepted_at`） |

- `flow`：**0 未记录 / 1 点滴 / 2 量少 / 3 中等 / 4 量多**（5 值枚举，避免"布尔 + 量级"的非法组合）。
- ⚠️ **不加 `is_period_day`**（恒等于 `flow IN (2,3,4)`，落库即同步风险）。
- 派生规则：出血日 = `flow ∈ {2,3,4}`，**点滴不参与周期划分**；连续出血归一组，**允许组内夹 1 天无出血**；间隔 ≥2 天断为新周期。

### 5.2 算法参数

| 项 | 值 |
|---|---|
| `C_hat` 周期中位数 | 28（**用中位数不用平均值**，一次漏记的 60 天"周期"能把均值拉偏 5 天以上） |
| `L_hat` 经期长度 | 5 |
| `Luteal` 黄体期 | 14（优先用体温法个性化，clamp 11–16） |
| `σ` | `1.4826 × MAD`（避免异常值把 σ 拉爆毁掉置信度分级） |
| 样本窗口 | **只取最近 6 个完整周期** |
| 易孕期窗口 | **6 天**（排卵日前 5 天 + 排卵日）；峰值 2 天 |
| PMS 窗口 | 7 天 |
| BBT 判定 | `+0.2℃ × 连续 3 天` |

### 5.3 置信度分级与 UI 强制约束

| 条件 | 级别 | UI 约束 |
|---|---|---|
| `N == 0` | `insufficient` | ⚠️ **不显示任何日期** |
| `N == 1` | `low` | 只显示区间，下限 `±max(4,⌈σ⌉)`、上限 7 天；排卵/易孕期**灰显** |
| `N ≥ 3 且 σ ≤ 1.5` | `high` | 显示**单日** |
| `σ ≤ 3.5` | `medium` | 显示区间 `±⌈σ⌉` |
| 其他 | `low` | 同上 |

> ⚠️⚠️ **绝对禁止**在 `low` / `insufficient` 下给出单一确定日期。

- 逾期：`overdue = today > next_start + half`；⚠️ **不显示醒目红色「已推迟 N 天」**，改中性文案，避免焦虑。
- 排卵日 `O = next_start − Luteal`；`fertile = [O−5, O]`、`peak = [O−1, O]`、`high = [O−5, O−2]`。
- ⚠️ UI 必须解释「易孕期从排卵日**往前**算 5 天」。
- 若 `O` 落到 `S` 之前 ⇒ 排卵与易孕期**整体隐藏**，只给下次经期预测。

### 5.4 「安全期」红线（不可违反）

| 规则 | 说明 |
|---|---|
| 称谓 | 必须是「**相对安全期**」 |
| 免责 | 必须紧邻一行「日历法推算，仅作参考，不能作为避孕依据」 |
| 颜色 | **中性浅灰蓝，禁用绿色**（绿色是"安全/通过"的正向暗示） |
| 开关 | `show_fertile_window = 0` 时安全期一并隐藏 |
| 区间 | `[O+2, next_start−1]` ∪ `[S+L_hat, O−6]`（后者需 ≥2 天）；**区间长度 < 2 天不标记** |

### 5.5 异常检测与免责

- 检测项：`CYCLE_SHORT <21`、`CYCLE_LONG >35`、`PERIOD_LONG >7`、`IRREGULAR`（最近 3 个与 `C_hat` 偏差均 >7 天）、`NO_PERIOD_90`、`SUSPECT_RECORD`（`cycle_length < 15`）。
- ⚠️ **所有 alert 后必须跟固定尾注**：「以上提示基于你的记录数据自动生成，不构成医学诊断」。
- 免责 5 条：预测数字前必须带「预计/预测」；low/insufficient 加灰并附说明；相对安全期固定免责行；首次进入弹一次免责确认（写 `disclaimer_accepted_at`）；任何 alert 后跟尾注。
- 目标模式 `goal`（1 仅记录 / 2 备孕 / 3 避孕参考 / 4 围绝经期）**只影响文案与默认展示顺序，不做功能阉割**。

### 5.6 边界

- 一次都没记录 → 引导卡。
- 只有向导填的 `last_period_start` → 视为 1 个不完整周期，`confidence = low` 并标注「基于默认 28 天周期」。
- ⚠️ **跨越 >90 天中断 → `cycle_length = NULL` 不计入统计**（不把"忘记录"当"超长周期"）。
- 不规则周期是**一等公民**，21–35 天之外**不判「异常」只提示**。

## 7. 明确不做

| 不做 | 理由 |
|---|---|
| 医疗级诊断 / 设备同步 / 孕期模式 | 合规与责任边界 |
| 应用锁 PIN | 已明确不做（隐私由卡片级遮罩承担，设备级 localStorage） |
| 用户级隐藏经期 Tab | Tab 常驻可见，隐私由遮罩承担 |
| 备孕专属功能 / 伴侣连接 / 社区知识库 | 与定位不符 |
| 症状预测 P1 之外的自动归因 | 猜错了用户极难纠正 |
