# 06 · 任务（待办）

> ⚠️ **路由命名坑**：移动端是 `/task`，**桌面端是 `/todo`**（目录名是 `pages/task`）。历史上出现过 `navigate('/task')` 跳 404。

---

## 1. 信息架构

```
任务列表（一级 Tab）
├── 移动端：SubTabBar 5 个筛选视图（同一实体的 5 个视图，语义正确，不动）
│     全部 all | 今日 today | 即将 upcoming | 已完成 done | 逾期 overdue
├── 桌面端：Semi Select 同 5 个值 + 优先级 Select + 搜索框
└── 详情页：移动 /task/:id（二级页，隐藏 TabBar）· 桌面 /todo/:id
```

**附加筛选**：移动端另有排序下拉（默认 / 截止时间 / 优先级 / 创建时间）；⚠️ **桌面端无排序控件**。

---

## 2. 数据模型

`tasks` 关键字段：

| 字段 | 值 |
|---|---|
| `status` | `todo` / `in_progress` / `done` / `archived` |
| `priority` | `relaxed` / `normal`（默认）/ `important` / `urgent` |
| `due_date` + `due_time` | 截止 |
| `reminder_at` | 提醒时间（⚠️ **写了但没人推**，见 [13](./13-通知与触达.md)） |
| `recurrence_rule` | `FREQ=DAILY/WEEKLY/MONTHLY`（⚠️ **只存不生成**） |
| `category_id` + `icon` | 分类（走 `user_categories` 的 `task` 域）+ 自选图标 |
| `parent_task_id` / `subtasks_count` | 父任务 |
| `subtasks` | 扁平子任务表（`title` / `is_completed` / `order`），**无嵌套** |

---

## 3. 详情页

桌面端 `/todo/:id` 内容：
- 返回 + 完成勾选 + 标题 + 状态/优先级 Tag + 截止/提醒/重复 meta chips
- 主体：描述 + 子任务（completed/total + 进度条 + 勾选切换）
- 侧栏「任务信息」：状态、优先级、截止、提醒、重复、子任务、创建、完成
- 编辑 / 删除（+ `TaskEditDrawer`）

重复展示字典 `RECURRENCE_LABEL` 只有 DAILY/WEEKLY/MONTHLY 三条，其余值透传原始字符串。

---

## 4. 交互与端差异

| 能力 | 移动端 | 桌面端 |
|---|---|---|
| 列表形态 | 卡片流 `TaskCard` + `van-list` 上拉加载 | Semi `Table` + `Pagination` |
| 编辑/删除 | **左滑**（`van-swipe-cell`） | 行内按钮 |
| 批量 | **长按进入多选模式** + 底部操作栏 | 表头 Checkbox 全选 |
| 表单 | 底部半屏 `TaskEditSheet` | `TaskEditDrawer` |
| 搜索 | 350ms 防抖 | 350ms 防抖 |

批处理能力：`POST /tasks/batch`，`action ∈ {complete, delete}`，一次 1–100 条。

---

## 5. 分类与图标

- 任务分类走 **`user_categories`（domain = `task`）**，一级平铺。
- ⚠️ **分类 id 保留旧值**（如 `c_work`），存量零迁移、统计 SQL 不改。
- 图标走 **`IconPicker`（仅 lucide）**，不再用 emoji（仅保留渲染兼容）。
- 选择器 `CategoryTiles`（新建的轻量版，不复用财务 `CategoryPicker`）。
- 任务自身 `icon` 为空时**继承分类图标**。
