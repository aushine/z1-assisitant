## 2. 落位规则（新功能该放哪）

### 2.1 决策流

```
每天 / 一天多次用？
├── 是 → 一级 Tab 或首页常驻卡
└── 否 → 是"录入"还是"查看"？
         ├── 查看 → 统计区块 / 报告页
         └── 录入 → 每周 ≥1 次？
                   ├── 是 → 记录模块二级 Tab
                   └── 否 → 「我的」（档案）+ 首页卡片入口
```

### 2.2 口诀

> **流水 → 记录**（每天往里灌数据）
> **档案 → 我的**（长期设定与资产）
> **镜子 → 统计**（把已有数据重新组织）
> **今天 → 首页**（不用点进去就该知道）

### 2.3 硬约束：二级 tab 最多 6 个

- 375px 下 `SubTabBar` 6 个是**等分铺满的上限**（62.5px）；7 个触发横滚（53.6px < `min-width:56px`），且第 6/7 个会"藏在右边看不见"。
- 320px（iPhone SE）下 **6 个就已横滚**。
- 一旦横滚，tab 条变成"横向可滚动祖先"，左右滑变成滚动而非切换模块。
- 记录页现用 3 个（习惯/财务/健康），**剩 3 个身位**；剩余身位**不送给「更多」**（"更多"是反模式）。
- 扩容发生在**「我的」**（档案，有页面纵深，不受 tab 配额限制）与**「统计」**。

## 4. 移动端布局与导航规范

| 项 | 规则 |
|---|---|
| 一屏高度 | 只认 `--app-height`；**禁用 `100vh`/`100dvh`/`height:100%`**；页面根不写 height |
| 滚动容器 | **body 是唯一滚动容器** ⇒ 顶栏**不 sticky** |
| Tab Bar | 底部胶囊，固定高 80px（Pill） |
| 内容区底部 padding | 100px（预留 TabBar + 安全区） |
| 页面水平内边距 | 20px |
| 区块垂直间距 | 16–20px |
| 二级页 | 走 `subpage.scss`（`.sub-page`/`.sub-body`）自管滚动，顶层路由**不挂 HomeLayout**（避免双滚动条） |
| 浮层 | ⚠️ `van-popup` **必须 `teleport="body"`（含嵌套）**，否则被布局层压住（不要靠调 z-index 解决） |
| iOS 26.7 胶囊带 | 五处负 inset 已归零 + `--tabbar-bottom-gap: 5px` |

## 5. 桌面端布局规范

| 项 | 值 |
|---|---|
| 侧边栏 | 宽 **260px**，内边距 `24px 20px`；导航项高 40px、圆角 10px、相邻间距 4px |
| Header | 高 **80px**，内边距 `0 32px` |
| 内容区 | `24px 32px`（<1200px 降为 24px），`max-width:1280px` 居中 |
| 导航分组 | 「个人功能」+「系统管理」两组，底部是用户卡 `UserQuickPanel` |
| 选中态底色 | `--color-primary-50` |
| 「我的」二级页宽度 | `.settings-page` = **600px**（profile/security/notifications/sync/help/about）<br>`.management-page` = **900px**（anniversaries/finance-categories/categories，要放列表行操作） |
| 表单容器 | `SideSheet` 抽屉优先（账户编辑/健康设置等）；图标选择用 `Modal`（居中 480–560px） |

## 7. 不改的东西（稳定约束）

- **5 个一级导航的名称与顺序**（首页 / 任务 / 记录 / 统计 / 我的）。
- 待办模块 5 个二级筛选（同一实体的 5 个视图，语义正确）。
- 移动端 `SubTabBar` 的 6 个上限（物理约束）。
- 记录模块 3 个二级 tab（习惯 / 财务 / 健康）。
