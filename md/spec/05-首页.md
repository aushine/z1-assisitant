# 05 · 首页

> 定位：**今天不用点进去就该知道的**。每天多次打开。

---

## 1. 区块结构

### 1.1 移动端（`pages/home/index.vue`）

| # | 区块 | 内容 |
|---|---|---|
| ① | **心情/精力卡** `MoodSection` | 置顶常驻，点选即 upsert（走 `/moods`） |
| ② | **4 张 KPI（2×2）** | 今日任务 → `/task`；今日习惯 → `/record`；本月支出 → `/stat`；本月收入 → `/stat`（金额走 `<MoneyText>`） |
| ③ | **管家建议** `SmartBanner` | `computeRecs(home, habits, now)` 本地推算，可操作 + 可关闭 + 轮播 |
| ④ | **今日时间线** `Timeline` | 跨 tasks / habit_logs / transactions / mood_logs 聚合 |
| ⑤ | **今日习惯** | 完成环（size 88）+ 最长连续 `longest_streak` + 逐条打卡按钮 |
| ⑥ | **本月财务** | 支出/收入 + 同比 + 分类占比 Top4 |
| ⑦ | **倒数日卡** `AnniversaryCard` | 最近 1–3 个「还有 N 天」；无数据整卡不渲染 |
| ⑧ | **快捷入口 4 宫格** | 记一笔（开半屏）、新建任务、去打卡、查看统计 |

顶部问候（头像 + 问候语 + 日期）由 `HomeLayout` + `PageHeader` hero 变体渲染，页面通过 `uiStore.setHomeHeader()` 推文案。

### 1.2 桌面端（`pages/home/index.tsx`）

| # | 区块 |
|---|---|
| ① | **问候条** `.welcome`：Sun 图标 + 日期文案 + 内嵌**心情/精力快捷点选**（MOOD 5 档 / ENERGY 3 档）+ **快捷入口 4 枚**（记一笔/新建任务/统计/我的） |
| ② | **4 张 KPI**（今日任务 / 今日习惯带进度条 / 本月支出 / 本月收入带 `KpiChange` 同比） |
| ③ | `SmartBanner` |
| ④ | **两栏区**：主区 = 今日时间线（占 2/3）；右栏 = ⑤ 今日习惯（环形进度 + 最长连续 + 打卡）、⑥ 本月财务、⑦ `AnniversaryCard`、⑧ `MoodSection` 完整卡 |

### 1.3 端差异（有意为之）

| 差异 | 说明 |
|---|---|
| 问候条承载位置 | 桌面在页面内；移动端提到 `HomeLayout` 常驻 |
| 布局 | 桌面两栏；移动单列 |
| 心情入口数量 | 桌面 2 处（顶栏快捷 + 侧栏卡）；移动 1 处（置顶卡） |
| 快捷入口取值 | 桌面「记一笔」跳 `/record`；移动直接开半屏 |
| 错误态 | 桌面整页 Skeleton / `ErrorState` 早返回；移动分区错误态 + 底部错误条 |

## 2. 数据流

| 数据 | 接口 | 说明 |
|---|---|---|
| 主数据 | `GET /home`（`home:view`） | KPI、财务、习惯概览 |
| 时间线 | `GET /timeline?date=`（`timeline:view`） | |
| 纪念日 | `GET /anniversaries/upcoming?limit=` | |
| 心情 | `GET /moods/today` + `PUT /moods` | 按小时 upsert |
| 习惯打卡 | `POST /habits/:id/log` | |

- 主数据与时间线用 **`Promise.allSettled` 并发**，各自独立 loading/error（单接口失败只让该分区显示错误态 + 重试）。
- 挂载时额外预拉：心情、习惯列表、账户、今日任务。

---

## 3. 关键规则

| # | 规则 |
|---|---|
| **H1** | 金额一律走 `<MoneyText>`（承载隐私遮罩），禁止裸 `formatMoney` |
| **H2** | 首页**没有独立的"今日任务卡"** —— 被 KPI「今日任务」+ 时间线吸收 |
| **H3** | 时间线视觉复用"圆点连线"规范（与健康今日时间轴同构） |
| **H4** | 倒数日卡无数据**整卡不渲染**（不留空卡） |
| **H5** | `SmartBanner` 是本地推算（`utils/smart-recs.ts`），不走后端 |
