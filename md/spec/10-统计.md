# 10 · 统计

> ⚠️ **二级 tab 是「领域」不是「区间」**。区间已降级为页内筛选器。

---

## 1. 结构

| 项 | 现状 |
|---|---|
| 二级 tab（领域） | **总览 / 健康 / 财务 / 习惯** |
| 区间 | 页内筛选器，**只有 7d / 30d / 90d**（类型位支持 `custom`，但**页内无 UI 入口**） |
| 默认区间（按领域） | 总览 `7d`、健康 `90d`、财务 `30d`、习惯 `30d` |
| 切领域 | **连带重置区间**到该领域默认值 |
| 移动端控件 | 页内 chips（`.range-chips`） |
| 桌面端控件 | `.page-tipbar` 右侧 Semi `RadioGroup type="button"` |

⚠️ **已知不一致**：桌面端 TabPane 顺序是 `总览 → 健康 → 习惯 → 财务`，与移动端的 `总览 → 健康 → 财务 → 习惯` 不同（见 [01 §6](./01-信息架构与导航.md) N1）。

---

## 2. 各领域内容

| 领域 | 内容 |
|---|---|
| **总览** | 今日任务 / 本周完成率 / 总净资产（**固定维度，不随区间**）+ 支出趋势（随筛选） |
| **健康** | 体重曲线（含 7 日均线，**<7 点不画均线**）、饮水达标率与连续达标、排便周频次柱图 + 形态分布饼图、体温曲线（含升温台阶 markPoint）；底部带「不构成医学诊断」免责 |
| **财务** | 支出趋势、支出分类占比（环形）、支出分类明细、账户汇总 |
| **习惯** | 习惯完成热力图（28 天）+ Top5 列表、习惯完成率（前 4） |

- ⚠️ `GET /stats/overview` **不接受 range**（DTO 无参）⇒ 总览里的三个数是**固定维度**，页内打「固定」badge；随筛选的打「随筛选」badge。
- 三个区间接口 `/stats/tasks`、`/stats/habits`、`/stats/finance` 用 **`Promise.allSettled` 并发**，单接口失败只让该分区显示错误态 + 重试。

## 3. 图表

| 端 | 库 |
|---|---|
| **移动端** | **ECharts**（`vue-echarts`，按需引入）+ `useChartTheme()` |
| **桌面端** | **Chart.js**（`react-chartjs-2`） |

⚠️ **canvas 吃不到 CSS 变量** ⇒ 移动端 `useChartTheme()` 从 `getComputedStyle(document.documentElement)` 反查 token，watch 主题 + `nextTick` 后重读再 `setOption`。**这是硬性要求不是可选项**。
⚠️ **桌面端 Chart.js 暗色不联动**是已知缺陷。

**热力图不走 ECharts**：手写 DOM 网格（需 `chinese-days` 的农历/节气/节假日/调休标注）。

**⚠️ 已知口径差**：桌面端饼图色用 `c.color || '#6B7280'` 兜底灰；移动端因后端 `by_category[].color` 恒为灰，改为**按 `category_id` 查分类 tint** 取真实色。

## 4. 导出

- 端点：`GET /stats/export`（权限 `stat:export`），**已接线，不是占位**。
- 参数：`type ∈ {all, transactions, tasks, habits}`、`range`（`custom` 需 `start_date` + `end_date`）。
- 返回：**原始 CSV 文件流**（`text/csv` + `Content-Disposition` + UTF-8 BOM），**不经 JSON 包装**。
- 入口：移动端顶栏「导出」→ `van-action-sheet` 四选一；桌面端 tipbar 右侧 `Dropdown` 四选一。

⚠️ **已知缺口**：只有 CSV，**且仅 3 类**（交易/任务/习惯）—— **无健康、经期、纪念日**；**无导入、无全量备份**。见 [99 §4](./99-附录.md)。

## 5. 关键规则

| # | 规则 |
|---|---|
| **S1** | 统计聚合**必须按分类 id**（`GROUP BY COALESCE(category_id, ...)`），不能按 name |
| **S2** | 财务分类聚合**必须含子分类归集** |
| **S3** | ⚠️ `week_completion_rate` 是 **0–100**，其余 rate 是 **0–1**（桌面端 `todo_rate * 100` 是 bug） |
| **S4** | 健康图表底部必须有「不构成医学诊断」免责 |
| **S5** | 金额展示走 `<MoneyText>`（受隐私遮罩控制） |
| **S6** | 热力图色阶**刻意保留 hex 字面量**，不令牌化（暗色翻转会破坏"越绿越多"的直觉） |
