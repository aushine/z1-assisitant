# 07 · 记录 · 习惯

> 记录模块共 **3 个二级 tab**：`习惯 | 财务 | 健康`。本篇讲习惯；财务见 [08](./08-记录-财务.md)，健康见 [09](./09-记录-健康.md)。

---

## 1. 定位与边界

| | 习惯 | 健康 |
|---|---|---|
| 问的问题 | **做没做**（行为打卡） | **测出来多少**（身体量化指标） |
| 数据形态 | 一天一次布尔 | 一天多次数值（events） |
| 例子 | 跑步、读书、冥想 | 饮水、体重、体温 |

> ⚠️ **饮水归健康，不归习惯**（它是量化的，不是布尔）。

---

## 2. 数据模型

| 表 | 关键字段 |
|---|---|
| `habits` | `name`、`icon`、`color`、`frequency`（daily/weekly/monthly）、`target`、`current_streak`、`longest_streak`、`last_check_in_date`、`total_check_ins`、`category_id` |
| `habit_logs` | `habit_id`、`date`（⚠️ 实际表名是 `habit_logs`，不是 `habit_records`） |

接口：`GET /habits`、`GET /habits/today`、`GET /habits/:id`、`POST /habits`、`PATCH /habits/:id`、`DELETE /habits/:id`、`POST /habits/:id/log`

---

## 3. 连续天数（streak）与里程碑

| 规则 | 说明 |
|---|---|
| **频率语义** | daily 单位「天」、weekly「周」、monthly「月」；文案与徽章随频率变化 |
| **视觉分档** | 同一个 `Flame` 图标，只递进底色：1–2 neutral / 3–6 warning / 7–20 橙 pill / 21–65 加重加粗 / ≥66 微光晕 |
| **里程碑** | **7 / 21 / 66 / 100 / 365** 天，图标 `Award / Medal / Trophy / Gem / Crown`，色值走 `--medal-*` |
| **中断预警** | `current_streak ≥ 7` 且今日未打卡且当前 ≥ **18:00**（⚠️ 早上催会反感）—— ⚠️ **依赖通知引擎，当前未实现** |
| **补签** | 每月 2 次、限最近 3 天、虚线边框、标记「含补签」—— ⚠️ **后端无端点，未实现**（streak 算法已能正确处理补签后重算，有单测） |

---

## 4. 分类与图标

- 习惯分类走 **`user_categories`（domain = `habit`）**，**只做一级**。
- ⚠️ **分类 id 保留旧值**：`sport` / `diet` / `life` / `study` 直接成为内置分类 id ⇒ **存量零迁移，统计按 id 分组的 SQL 一行不用改**。
- 图标走 **`IconPicker`（仅 lucide）**；⚠️ 后端已**删除** `habit.category` 的硬枚举校验（原 `v:"in:,sport,diet,life,study"`）。
- 管理入口：**我的 → 分类管理**（与待办共一页，页内分段）。

---

## 5. 打卡交互

| 端 | 交互 |
|---|---|
| 移动端 | 首页「今日习惯」环 + 逐条打卡按钮；记录页习惯 tab 内打卡 |
| 桌面端 | 首页右栏环形进度 + 打卡；记录页习惯 tab |

- 打卡接口 `POST /habits/:id/log`，参数名是 **`date`**（⚠️ 早期 `log_date` 是静默失效的 bug）。
- 习惯热力图：28 天，5 档色阶 `F3F4F6 / D1FAE5 / 6EE7B7 / 34D399 / 10B981`；⚠️ **刻意保留 hex 字面量不令牌化**（顺序色带暗色翻转会破坏"越绿越多"的直觉）。
