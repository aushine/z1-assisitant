### 1.5 暗色

- `--color-*` 体系**曾经完全没有暗色适配**（361/378 处引用）。现已按语义组补齐。
- 图表 canvas 吃不到 CSS 变量 ⇒ 移动端用 `useChartTheme()` 从 `getComputedStyle(document.documentElement)` 反查 token 并 watch 主题重设；桌面端 Chart.js **暗色不联动是已知缺陷**。
- 品牌 logo 在暗色下**加白色底托**（不做双套资源），但 `z1-mark` 需按主题切 `z1-mark-white.svg`（SVG 内部 `fill` 硬编码，无法用 `currentColor`）。

## 6. 图标系统

### 6.1 选型与版本

- **Lucide**，两端分别 `lucide-react@0.300.0` / `lucide-vue-next@0.300.0`。
- ⚠️ **必须锁精确版本 `0.300.0`**，不能用 `^` —— 一次 `npm i` 漂移就会让几十个图标集体失联。
- 早期评估过 IconPark，已放弃：仓库已归档、解包 10.5MB、48 网格且 `stroke-width` 写死在 SVG 内部（外部改不了 ⇒ 尺寸标度作废）。

### 6.2 尺寸（6 级 + 光学补偿：越大越细）

| 级 | 尺寸 | stroke |
|---|---|---|
| xs | 14 | 2.25 |
| sm | 16 | 2 |
| **md（默认）** | 20 | 1.75 |
| lg | 24 | 1.75 |
| xl | 32 | 1.5 |
| 2xl | 48 | 1.25 |

- **禁止**语义档位（`size="small"`）、**禁止** `style.fontSize`、禁止 `as any`。
- 业务代码**只从 `@/components/icon` 导入**，不得直引 lucide。

### 6.3 命名白名单（关键）

- 两端 `src/components/icon/names.ts` 导出 `ICONS` 注册表（约 270 个），**逐字一致**，文件头带 `SYNC-FROM-*` 注释与同步日期。
- ⚠️ **0.300.0 用旧命名**，新版官网名字很多不存在：

| 新版名（不存在） | 0.300.0 等价名 |
|---|---|
| `NotebookPen` | `PenLine` |
| `ChartColumn` | `BarChart3` |
| `ChartPie` | `PieChart` |
| `HandCoins` | `Banknote` |
| `SquarePen` | `Pencil` |
| `SquareCheck` / `CircleCheck` | `CheckSquare` |
| `CirclePlus` | `PlusCircle` |
| `House` | `Home` |
| `CircleAlert` / `TriangleAlert` | `AlertTriangle` |
| `LoaderCircle` | `Loader2` |
| `Ellipsis` | `MoreHorizontal` |
| `CircleHelp` | `HelpCircle` |

- 兜底：未命中 → `HelpCircle` + DEV `console.warn`（**禁止静默降级**）。

### 6.4 图标分组与自选

- `ICON_GROUPS`：**14 组 ≈ 220 个**（食品饮品 / 交通出行 / 购物消费 / 居住家居 / 娱乐休闲 / 医疗健康 / 学习教育 / 人际人情 / 母婴育儿 / 宠物动物 / 金融钱币 / 办公工作 / 运动健身 / 旅行度假）。
- 规则：`ICON_GROUPS` **只允许引用 `ICONS` 里的名字** ⇒ 入库的图标名必定可渲染。
- 两端 `ICON_GROUPS` 逐字一致 + SHA256 校验。

### 6.5 配色三级规则

1. **默认 `currentColor` 不着色**（覆盖绝大多数）。
2. **只有颜色本身携带信息时才着色**（KPI 标识 / 状态标签 / 趋势箭头 / 预警）。
3. **彩色圆底 + 图标 = 只用 `IconBox`**，且只用 **6 种 tint**，**同屏最多 4 种**：

| tint | 底 / 图 |
|---|---|
| primary | `#E0F2FF` / `#014DB2` |
| success | `#D1FAE5` / `#047857` |
| warning | `#FEF3C7` / `#B45309` |
| danger | `#FEE2E2` / `#B91C1C` |
| accent | `#EDE9FE` / `#6D28D9` |
| neutral | `#F3F4F6` / `#6B7280` |

> ⚠️ 移动端铁律：**「彩色圆底 + 图标」一律用 `IconBox.vue`**；禁止给 `<Icon>` 加 class 设宽高。
> 卡片标题图标**不包彩色圆圈**，改裸图标 + 继承文字色。

### 7.3 品牌使用红线

- **不自绘、不改色**（Z 与 1 的色值不得对调），直接取用素材。

- 银行/品牌 logo 属各自商标，此处为**指示性使用**（识别用户自己的账户）；保留 `SHOW_BANK_LOGOS` 开关可一键降级为文字徽标。

## 8. 组件级约定

| 组件 | 规则 |
|---|---|
| **`IconBox`** | 所有「彩色圆底 + 图标」的唯一出口 |
| **`MoneyText`** | 所有财务金额展示的唯一出口（承载金额遮罩），见 [08 §7](./08-记录-财务.md) |
| **`BrandLogo`** | 三态渲染：`brand:<slug>` → `<img>`；`lucide:<Name>` → `<Icon>`；其他 → emoji 兼容。加载失败 → 文字徽标（**绝不裂图**） |
| **空态 / 错误态** | 统一 `<ErrorState>` / `<EmptyHint>`；错误态判定 `error && !loading && list.length === 0` |
| **Toast** | 统一走 `utils/feedback.ts`，见 [11 §5](./11-我的.md) 与 [99 §3](./99-附录.md) |
| **热力图** | ⚠️ **刻意保留 hex 字面量不令牌化**（顺序色带暗色翻转会破坏"越绿越多"的直觉） |
