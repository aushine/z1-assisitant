# 05 · 周期切换交互改造（R5）

> **性质**：需求｜**端**：双端｜文件：`life-assisitant-ui-mobile/src/components/finance/SummaryCards.vue`

---

## 1. 现状

- 位置：流水视图顶部 `SummaryCards`（`components/finance/SummaryCards.vue`），挂在 `TransactionList.vue:284`。
- 右卡标题「剩余预算 · **月**」，那个「月/周/年」**单字**是一块带虚线下划线的点击热区：
  ```html
  <span class="sum-period" @click.stop="store.cycleSummaryPeriod()">{{ periodShort }}</span>
  ```
- 点击**循环切换**：月 → 周 → 年 → 月（`stores/finance.ts` L655 `cycleSummaryPeriod()`）。
- 持久化：localStorage key `ls:finance:summaryPeriod`。
- 错误态也有同款热区（L73）。

## 2. 目标（用户决策 D6）

- **改为 B：下拉/弹层选择**（不做 A 分段控件，也不保留「点单字循环」）。
- 点周期字 → 弹出选项（周 / 月 / 年）→ 选中即切换并持久化。

## 3. 交互设计

### 3.1 移动端
- 点「月」→ 弹出 Vant `ActionSheet` / `DropdownMenu`，列出「本周 / 本月 / 本年」，当前项高亮。
- 选中 → `store.setSummaryPeriod(p)`（已有方法，L648）→ 立即 `fetchSummary()`。
- 触发热区仍是标题里的周期字，但加一个 `ChevronDown` 小箭头提示「可下拉」。
- 错误态热区同步改造。

### 3.2 桌面端
- 用 Semi `Select` / `Dropdown`（周/月/年），样式与桌面端其它筛选一致。
- 桌面端若有同类「点单字循环」的组件，一并改。

## 4. 状态

- 仍用 `ls:finance:summaryPeriod`（week/month/year），默认 month。无新增存储。
- 顺序：下拉里按自然顺序 **周 → 月 → 年**（不再用「循环」语义）。

## 5. 验收

- [ ] 点周期字出现**下拉/弹层**（周/月/年三选一），非循环
- [ ] 选中有当前项高亮
- [ ] 选择持久化（刷新后保持）
- [ ] 双端一致
- [ ] 四个数（收入/支出/剩余预算/结余）随周期同步刷新

## 6. 端差异

| 端 | 控件 |
|---|---|
| 移动 | Vant ActionSheet / DropdownMenu |
| 桌面 | Semi Select / Dropdown |
