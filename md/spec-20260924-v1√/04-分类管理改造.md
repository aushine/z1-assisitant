# 04 · 分类管理改造（R4）

> **性质**：需求｜**端**：双端｜文件：`life-assisitant-ui-mobile/src/pages/me/categories.vue`

---

## 1. 现状

- 入口：**我的 → 分类管理**，习惯与待办**共一页**，页内用 **tab/分段** 切换 habit / task。
- 用户反馈：**不要 tab 切换**。

## 2. 目标

- **从各自入口进，各自独立**：
  - 从「待办」侧进入 → 页面只显示**待办分类**，标题「**待办分类管理**」。
  - 从「习惯」侧进入 → 页面只显示**习惯分类**，标题「**习惯分类管理**」。
- **去掉页内分段/tab 切换**。
- 二级分类管理一并纳入（见 03 文档）：能看一级、展开二级、对二/一级增删改。

## 3. 交互设计

### 3.1 移动端
- 两个入口（「待办」设置区、「习惯」设置区各一个「分类管理」入口），各自带 `domain` 参数进同一页面。
- 页面标题随 `domain` 变化。
- 列表：一级项为卡片/行；有二级的显示 `ChevronRight` 可展开；展开后显示二级子项。
- 增删：长按（`useLongPress` 500ms，⚠️ 禁用 `@contextmenu`）→ 操作菜单（编辑/删除）。有二级的一级另有「添加二级」。

### 3.2 桌面端
- 侧栏/设置区两个入口，各自跳转到分类管理页并带 domain。
- 用 `Tree` 或可展开表格：一级行 + 缩进二级行。
- 增删：行内按钮 / 右键 Dropdown（hover 显 `⋮`）。

## 4. 路由

- 移动端：现有入口 `pages/me/categories.vue` → 接收 `domain` 参数（query 或 route params）。
  ⚠️ 若原路径是 `/me/categories` 单页带 tab，改为 `/me/categories?domain=task` / `?domain=habit`。
- 桌面端：对应 `/me` 下分类管理入口，同样带 domain。

## 5. 接口
复用 `GET /user-categories?domain=xxx`（见 03 §6）。**不再需要一次拉两个 domain**。

## 6. 验收

- [ ] 待办入口进去只显示待办分类，标题「待办分类管理」
- [ ] 习惯入口进去只显示习惯分类，标题「习惯分类管理」
- [ ] 页面**无** habit/task 分段或 tab
- [ ] 二级分类可展开、可增删改（依赖 R3）
- [ ] 双端一致

## 7. 端差异

| 能力 | 移动端 | 桌面端 |
|---|---|---|
| 布局 | 可展开列表 | Tree / 可展开表格 |
| 增删入口 | 长按 | 右键 / 行内按钮 |
