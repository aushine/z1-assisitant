## S2. 过渡动画：串行 `out-in` → 重叠 / 极短

### 现状
`HomeLayout.vue`：
```html
<transition name="fade-page" mode="out-in">
```
```scss
.fade-page-enter-active, .fade-page-leave-active {
  transition: opacity var(--duration-page) var(--ease-default); /* 130ms */
}
```
`mode="out-in"` ⇒ 旧内容**先淡出完（130ms）**，新内容**才开始淡入（130ms）**，总 **260ms**，
中间有一段"没有内容"的空档。

### 目标
- 淡出与淡入**重叠**（去掉 `mode="out-in"`），或采用"新内容立即入场 + 旧内容快速退场"。
- 总感知时长 **≤ 120ms**。
- 配合 S1（KeepAlive 后新内容已就绪），过渡只是"锦上添花"，越短越好。

### 规则
- **去掉 `mode="out-in"`**：Vue 默认 `mode` 为同时进出（`in-out` 的相反即默认"同时"）。
  ⚠️ 同时进出要求"新旧两个组件并存"——但 5 Tab 页是**同位置渲染同一个 `<component>`**，
  同一时刻只有一个。去掉 out-in 后，进入/离开是同一 DOM 的透明度过渡，观感为"快速交叉"。
- 时长下调：离开/进入各 **~90ms**，用 `--duration-instant`（80ms）或新增 token `--duration-page-fast`。
- **必须**尊重 `prefers-reduced-motion`：
```scss
@media (prefers-reduced-motion: reduce) {
  .fade-page-enter-active, .fade-page-leave-active { transition: none; }
}
```

### 不动的部分
- `App.vue` 的 `.fade-layout`（登录 ↔ 主应用）：**保留 out-in**。这是一次性场景，
  且布局整体替换，重叠会看到两个布局叠影。
- 桌面端：无过渡，保持。

## S3. 骨架屏兜底

### 为什么
即使 S1 缓存 + S2 动画，仍有两处会留白：
1. **首帧**：某 Tab 第一次进（缓存未命中），数据在飞行中。
2. **强刷/切库后**：数据被清、重新拉。

这时的"白"要靠骨架屏消除——用户看到"结构已就位、内容在填"，
主观上不觉得卡，比裸 spinner / 空白好得多。

### 规则
- 用 Vant `van-skeleton`（`@vant/auto-import-resolver` 已配，模板直接 `<van-skeleton>` 即可）。
- 骨架**贴合各页真实布局**（不求像素级一致）：
  | 页 | 骨架 |
  |---|---|
  | Home | 心情卡 1 块 + KPI 4 小块 + 时间线 3 行 |
  | Task | tab 下 4~5 行卡片 |
  | Record | 分段标题 + 4 行 |
  | Stat | 图表占位 1 大块 + 2 行 |
  | Me | 头像行 + 3 组列表项 |
- **触发时机**：仅「首拉（`firstDone=false`，见 S1 §3.2）」显示；静默刷新**不显示**。
- 现有各页若已有 loader，替换为骨架（视觉更稳）。
- 桌面端：空白感低，**本批不新增**（若已有 Semi `Skeleton` 则保留）。
