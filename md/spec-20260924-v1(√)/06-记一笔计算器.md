# 06 · 记一笔计算器（R7）

> **性质**：需求（**回归修复** —— spec 已有设计但未实现）｜**端**：双端
> **文件**：键盘 `components/finance/AmountPad.vue`；宿主 `components/TransactionEditSheet.vue`
> **基准设计**：`md/spec/08-记录-财务.md` §2.1（本项多为其**回归落地**）

---

## 1. 问题

用户反馈：「记一笔页面的计算盘打开后**图标会跑到上面**，不是我要的效果。
我要的效果是**计算盘和金额框组成计算器**。」

### 现状（代码实况）
- `AmountPad.vue` 模板 L191-244：键盘 `absolute` 贴浮层底部，顶部有个**抓手条 `.pad-grab`**：
  ```html
  <div class="pad-grab">
    <span class="grab-bar" />                              <!-- 36×4 单杠 -->
    <Icon class="grab-arrow" name="ChevronDown" :size="12" />  <!-- ↓ 箭头 -->
  </div>
  ```
  → 这个「单杠 + ChevronDown」就是用户说的「**图标跑到上面**」。
- 金额框与键盘各在 `.sheet-body` / `.pad` 里，**未组成一块**。

### 期望（= spec 08 §2.1 原文）
> 键盘与金额框「**组成一块**」（移动端）：
> - 金额框**同一 DOM 元素、不隐藏、不重建**，键盘升起时**平移到键盘正上方**；
> - ⚠️ 金额框**必须移出 `.sheet-body`**（放进覆盖层 `.calc-dock`），否则被 `overflow` 裁剪；
> - 视觉四条件：上下零缝隙 + 共用外圆角（金额框 `20 20 0 0`）+ 同一底色且**删掉键盘原有 `border-top`** + 投影只加在金额框上；
> - ⚠️ `--calc-dock-h` 用 **ResizeObserver 运行时测量**（写死 token 会导致改键盘高度时忘改留白，最后一个字段被压住且不报错）。

## 2. 改动方案

### 2.1 结构（移动端）
```
.calc-dock（覆盖层，固定底部）
├── .amount-card           ← 金额框（同一 DOM，不隐藏不重建）
│     border-radius: 20px 20px 0 0
│     box-shadow: 投影仅在此
└── .amount-pad            ← 键盘（删掉 border-top）
      （无独立抓手条；由 Dock 整体高度与金额框组成一块）
```

### 2.2 关键点
1. **金额框移出 `.sheet-body`**，放进 `.calc-dock`。
2. **删掉/改造 `.pad-grab`**：不再让「单杠+箭头」独立浮在上方 → 用户看到的不再是「图标跑到上面」。
   - 若仍需「收起键盘」手势：把收起交互改为**下拉整个 dock** 或点金额框，而非一个突兀的箭头。
3. **零缝隙**：金额框底 `2020 0 0`，键盘顶圆角 0，中间无 margin/border/padding。
4. **同一底色** + 删键盘 `border-top` + 投影只加金额框。
5. **`--calc-dock-h` 用 ResizeObserver 测量**（响应式留白），不用写死 token。

### 2.3 桌面端
- 桌面端为**表达式输入 + 失焦采纳**（`199/3` → `63.33`），无计算盘。
- 本项桌面端**不涉及**（保持现状），仅需确认移动端改完后桌面端记一笔不受影响。

---

## 3. 验收

- [ ] 打开记一笔时，金额框与键盘**视觉上是一整块计算器**（零缝隙、共用圆角、同底色）
- [ ] 无「图标/抓手条跑到上方」的突兀元素
- [ ] 金额框不因键盘升起而隐藏/重建
- [ ] 不留白错位（最后一个字段不被压住）
- [ ] 桌面端记一笔表达式输入不受影响
