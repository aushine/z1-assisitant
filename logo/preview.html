z1 品牌标识 · v3

Z1 并置，用明度讲 zero → one。Z 用 primary-300、1 用 primary-500 —— 视线先落在 1，再回看 Z，阅读顺序本身就是 zero 到 one 的方向。

主标识

浅蓝底 #E0F2FF · Z #4D94FF · 1 #014DB2

全部取自设计令牌 tokens.scss，未引入新色。笔画端头平切，1 的旗角斜率与 Z 斜笔严格平行（55°）—— 这是两个字符「是一套字」的关键。

主屏上的 z1 与相邻图标并列时不会被吃掉 —— 因为底色 #E0F2FF 在一片白色图标中形成柔和的色块，而 1 的深蓝保证了图形不失焦。

锁定组合：横版 / 竖版 / 宽幅

主标识是正方形，只用于 App 图标位。页头、登录页、关于页、启动图、邮件签名需要的是横向展开的锁定组合 —— 图形与 slogan 的间距、字号比例、色彩分配都独立定过参数。

z1-lockup-h —— 主横版（透明底，2.51:1）。浅色页面直接用，图形与 slogan 之间留 52 单位净空。

左 z1-lockup-h-white（白底，用于需要实底的地方）· 右 z1-lockup-h-brand（品牌蓝底反白，用于深色页面 / 图片上）

z1-lockup-v · z1-lockup-v-brand —— 竖版（0.90:1，近方形）。slogan 宽度锁定为图形宽度的 95%，主副分明；用于启动页、关于页头部、社交头像位。

z1-banner —— 3:1 宽幅（1440×480 基准），内容居中、四周大片留白。用于 README 头部、邮件签名、演示文稿封面。

z1-lockup-h-icon —— 需要延续 App 图标形态时的备选（圆角方块 + slogan）。干净度不如无底版，但视觉上更「产品」。

已实测废掉的路线

以下结构都渲染验证过，不必再试：

  • 圆环 + 顶部竖线 → 同构于电源开关符号 ⏻
  • 圆环切线冲出竖线 → 只能产出 b 或 d
  • 竖线贯穿圆环 → φ；竖线穿右缘 → a / Q
  • 实心圆挖出 1 → 读成 7
  • 生长环 / 锥度环 → 相机镜头 / 光圈 / 同步图标
  • Z 底横连笔接 1 → 底部粘连读成一整块
  • Z 右侧封顶竖 → Z] / ZL，1 消失
  • 1 从 Z 斜笔分叉 → 糊成 4
  • 同笔画内由虚到实 → 分界像渲染瑕疵
  • 叠印半透明 1 → 像渲染鬼影
  • Z 斜笔改曲线 → 手写体，丢锋利
  • Z 横笔右端斜切 → 读成 2
  • 横版里再放一个小 Z1 字标 → 屏幕上两个 Z1，读成「Z1 Z1」
  • 横版 slogan 用浅蓝渐层 → 对比不足，像没印实
