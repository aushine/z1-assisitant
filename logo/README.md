# z1 品牌标识规范 v3

> 方形画布 1024×1024 · 圆角 229（22.36%，iOS squircle 等效）· 全部色值取自
> `life-assisitant-ui-mobile/src/styles/tokens.scss`，未引入任何新色。

---

## 一、概念

**Z1 并置，用明度讲 zero → one。**

`zero to 1` 不靠笔画连接来表达（连接会让两个字符糊成一团，已实测废掉），
而是交给**色阶**：

| 字符 | 含义 | 色阶 | 感受 |
|---|---|---|---|
| **Z** | zero | `#4D94FF` primary-300 | 浅、轻、还没成形 |
| **1** | one | `#014DB2` primary-500 | 深、重、已经落地 |

视线先落在 **1**，再回看 **Z** —— 阅读顺序本身就是 zero → one 的方向。
这条叙事恰好落在系统自己的浅蓝语言里，所以在界面里不像"贴上去的"。

## 二、字形逻辑

两个字符必须是**同一套字**，不是拼在一起的两个字母。约束如下：

- **端头一律平切**（不用圆头）。圆头会让 Z 读成"某种字体的字母"，平切才是标识。
- **旗角斜率 = Z 斜笔斜率**，两者都是 `100/70 = 1.4286`（约 55°）。
  这是"一套字"的关键——旗角与斜笔平行，眼睛才会把 Z 与 1 认成一个整体。
- **1 的高度 = Z 的 1.10 倍**。数字的 cap height 本就高于 x-height，1 略高是排版事实，也让 one 自然出头。
- **1 的笔画比 Z 粗一档**（38 : 36）：落地的比没落地的重。
- Z 转角圆角半径 = 笔画宽的 10%，与系统 16px 圆角语言同族。

## 三、色彩规范

### 主配色（浅底）

| 用途 | Token | HEX | RGB | 面积 |
|---|---|---|---|---|
| 底 | `--primary-50` | `#E0F2FF` | 224, 242, 255 | ~62% |
| Z（zero） | `--primary-300` | `#4D94FF` | 77, 148, 255 | ~22% |
| 1（one） | `--primary-500` | `#014DB2` | 1, 77, 178 | ~16% |

### 暗色主题

| 用途 | Token | HEX |
|---|---|---|
| 底 | `--primary-900` | `#002A66` |
| Z（zero） | `--primary-300` | `#4D94FF` |
| 1（one） | — | `#FFFFFF` |

### 品牌蓝底（图标场景）

| 用途 | HEX |
|---|---|
| 底 | `#014DB2` |
| Z / 1 | `#FFFFFF`（同色，靠形状区分） |

### 对比度校验

- 主配色：`#014DB2` on `#E0F2FF` = **8.1:1**（AAA）
- 主配色：`#4D94FF` on `#E0F2FF` = **2.9:1**（大字 / 图形可接受，不用于正文）
- 暗色：`#FFFFFF` on `#002A66` = **12.6:1**（AAA）
- 暗色：`#4D94FF` on `#002A66` = **4.5:1**（AA）

## 四、文件清单

### `primary/` — 主标识与工程变体

| 文件 | 用途 |
|---|---|
| `z1-icon.*` | **主标识**。浅蓝底圆角版，用于应用内品牌位、favicon、网页 |
| `z1-icon-square.*` | 满幅方形（无圆角）。**iOS / Android 图标源文件**，平台自己切圆角 |
| `z1-icon-dark.*` | 暗色主题版（`#002A66` 底） |
| `z1-icon-brand.*` | 品牌蓝底反白。需要"远看有分量"时用（应用市场、推广图、桌面快捷方式） |
| `z1-icon-maskable.*` | Android maskable。主形缩到 52% 安全区，任意裁切不被切到 |

### `variants/` — 无底与单色

| 文件 | 用途 |
|---|---|
| `z1-mark.*` | 无底纯图形（Z 浅 / 1 深）。放在白/浅底页面上直接用 |
| `z1-mark-mono.*` | 单色 `#014DB2`。印刷、单色场景、水印 |
| `z1-mark-white.*` | 纯白。深色底、照片上 |
| `z1-mark-mono-sq.*` | 单色 + 浅蓝底方形 |

每个文件均附 **SVG 源文件** + **10 档 PNG**（1024 / 512 / 256 / 192 / 128 / 96 / 64 / 48 / 32 / 16）。

### `lockup/` — 横版标识体系（图形 + slogan 锁定组合）

> 方形 App 图标之外的场景：登录页、关于页、官网头图、文档页眉、分享卡片。
> 图形与 v3 主标识**完全同一套几何**，slogan 不再是"使用建议"，直接做进了文件。

| 文件 | 结构 | 用途 |
|---|---|---|
| `z1-lockup-h.*` | **横版标准**：无底 Z1 + slogan 右置 | 页面页眉、文档标题、浅色界面 |
| `z1-lockup-h-white.*` | 横版 + 纯白底 | 白底文档、PPT |
| `z1-lockup-h-brand.*` | 横版 + 品牌蓝底反白 | 深色场景、推广头图 |
| `z1-lockup-h-icon.*` | 横版（图标方块 + slogan） | 仅当版面需要"方块锚点"时用；⚠️ 与 Z1 并置版二选一，**不得同屏出现**（会出现两个 Z1） |
| `z1-lockup-v.*` | **竖版**：Z1 上、slogan 下 | 登录页、启动页、正方形头像位 |
| `z1-lockup-v-brand.*` | 竖版品牌蓝底 | 深色登录页 |
| `z1-banner.*` | **3:1 宽幅**，整体居中 | 官网 banner、关于页头图 |
| `z1-banner-brand.*` | 3:1 宽幅品牌蓝底 | 深色 banner |

PNG 档位：横版 400–2400、竖版 240–1200、banner 800–2880（按宽度命名）。

**锁定组合的排版参数（已扫描定稿，勿随意改）：**

- slogan 字号 = 图标高 × **0.32**（0.235 太空、0.37 抢主体）；字重 **700**（600 偏弱）
- 图形与 slogan 间距 = 图标高 × **0.26**（0.34 太空）
- 深底反白时 Z 用 `#9CC2FF`（比 primary-300 更亮，深底上才立得住），1 用纯白
- **竖版特例**：slogan 宽度 = Z1 图形宽 × **0.95**。直接沿用横版字号会让 slogan 比主图形还宽，主副颠倒
- slogan 配色：`ZERO TO` 灰 `#6B7280` + **「1」用品牌蓝 `#014DB2`**——slogan 本身也在讲 zero→one

## 五、使用规范

- **最小尺寸 16px**。16px 下旗角会退化，但 Z1 的整体轮廓仍成立。
- **四周留白 ≥ 图标宽度的 10%**，不得压边。
- **不得改底色**为系统调色板之外的颜色；浅底版不得配深色页（用 `-dark`）。
- **不得单独取用 Z 或 1** 作为标识（两者是一体的）。
- Z 与 1 的色值**不得对调**（对调就变成「1 是零、零是一」，叙事反了）。
- slogan `ZERO TO ONE` 是**独立文案**，不并入图形。**优先直接使用 `lockup/` 下的成品**；
  只有在 lockup 覆盖不到的版式里才手工排，参数照 `lockup/` 章节的定稿值：
  - 字体：系统 sans（`Inter` / `PingFang SC` / `Segoe UI`），字重 700
  - 全大写，字号约为图形高度的 32%（横版）
  - 颜色：浅底 `ZERO TO` 用 `#6B7280`、「1」用 `#014DB2`；深底 `ZERO TO` 用 `#9CC2FF`、「1」用纯白

## 六、小尺寸表现

| 尺寸 | 保留 | 变化 |
|---|---|---|
| 256px+ | 全部细节 | — |
| 96–128px | 旗角、圆角、明度差 | 不变形 |
| 48–64px | 明度差仍可辨，旗角略钝 | 圆角视觉上更收紧 |
| 32px | Z1 轮廓清晰 | 旗角接近退化 |
| 16px | 「两个蓝色块的 Z1」 | 旗角基本消失，靠明度差区分 |

## 七、已实测废掉的路线（勿重复尝试）

| 结构 | 结果 |
|---|---|
| 圆环 + 顶部竖线 | 同构于**电源开关符号** ⏻ |
| 圆环开口切线冲出竖线 | 数学上只能产出 **b** 或 **d** |
| 竖线贯穿圆环 | 读成希腊字母 **φ** |
| 竖线穿圆环右缘 | 读成 **a / Q** |
| 实心圆挖出「1」 | 读成 **7** |
| 生长环 / 锥度环 | 读成**相机镜头 / 光圈 / 同步图标** |
| Z 底横连笔接 1 | 底部粘连，读成一整块 |
| Z 右侧封顶竖 | 读成 **Z]** / **ZL**，1 消失 |
| 1 从 Z 斜笔分叉 | 糊成一个 **4** |
| Z 笔画由虚到实（同笔画内渐变） | 分界像**渲染瑕疵** |
| 叠印 / 半透明 1 | 像**渲染鬼影** |
| Z 斜笔改曲线 | 变手写体，丢锋利 |
| Z 横笔右端斜切 | 读成 **2** |
